## Known non-failures

- Codex, Claude Code, OpenCode, Hermes, OpenClaw and Antigravity show unavailable when their CLIs are not installed in this environment. This is correct detection, not a UI failure.
- MCP, n8n, Paperclip, Browser and YouTube remain adapter-required/not-configured until real adapters and permissions are provided.
- Durable 24/7 execution is not claimed yet; the current local runtime is a foreground process with an event stream.
